How Briefly works

Under the hood

An agent you can inspect.

Briefly connects a language model to real research tools. The model decides what to use, works through the results, and keeps your follow-up questions in context.

Explore the API
01 / REQUEST

FastAPI + Agents SDK

A Python service receives your question and session ID. SDK-native memory carries the conversation across turns.

02 / RESEARCH

Three MCP integrations

Tavily searches the web. Open-Meteo provides forecasts. Filesystem tools read and save workspace files.

03 / SYNTHESIS

NVIDIA NIM → your brief

The model combines tool results into an answer, selects another tool when needed, and returns the briefing.

Deployed on Google Cloud Run · Real MCP discovery and tool calls · Credentials stay on the server · Workspace file access is restricted to its data directory
