# Project working conventions

- Append substantive user instructional prompts to `prompts.md` with the date and context. Preserve wording but never record credentials.
- Treat the assignment PDF as requirements reference, separate from the user's current requested scope.
- Keep secrets in the ignored `.env`. Never display, commit, or copy keys into documentation.
- Use `.venv/bin/python` for this project. Keep `requirements.txt` pinned to the installed dependencies.
- Record actual verification outcomes in `PROCESS_LOG.md`; do not invent successful API calls, completed features, or the student's personal learning reflections.
